## Проверки перед переиспользованием

Минимальный будущий regression набор: один snapshot каждого реально используемого класса → PNG golden; кириллица/длинное слово/nonzero letterSpacing/rich run внутри слова; разные renderer/validator payloads; missing required asset; несколько photo slots и замена одного source; EXIF/preview-original crop; stale signed URL; in-flight cache clear; два параллельных import writer; fail после каждого remote write; repeated confirm после timeout. Эти проверки нужны до оценки сохранности вывода, а не после замены storage. Никакие тесты или dependencies этим аудитом не добавлены.
