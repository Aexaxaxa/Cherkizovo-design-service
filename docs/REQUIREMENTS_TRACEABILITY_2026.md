## Как читать матрицу

- Формальные IDs сохранены: ARC-FIG-01/02, ARC-YD-01/02/03, TPL-TXT-01…05, UX-NAV-01…04 — всего 14. Другие строки названы по предмету требования, без вымышленных IDs ТЗ.
- ALREADY MET означает соответствие проверенной кодовой части, не успешную production приемку. PARTIALLY MET — механизм есть, но требование реализовано не полностью. NOT MET — требуемого механизма/поведения нет. CONFLICTS WITH CURRENT ARCHITECTURE — текущий подход прямо расходится с целевым. REQUIREMENTS / PARAMETER OPEN — ТЗ намеренно не задаёт окончательное значение. NOT APPLICABLE используется только для функций, сознательно исключённых из scope.
- При отсутствии реализации evidence — соответствующие существующие ближайшие блоки и инвентарь tracked app/lib/package; это не догадка по README. Для каждой строки приведено действие; будущие acceptance/regression проверки вынесены отдельно.
- Ссылки `path:line` — locators текущего SHA; имена функций можно найти в [ARCHITECTURE_CURRENT.md](ARCHITECTURE_CURRENT.md). Сроки/параметры target не выводятся из текущих defaults.
